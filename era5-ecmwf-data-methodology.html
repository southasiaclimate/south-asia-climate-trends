How We Get Our Climate Data: ERA5, ECMWF & Open-Meteo Explained

Published September 14, 2026 · Methodology

Every trend, chart, and figure on this site — across all 9 cities and locations — comes from the same underlying data pipeline. This page explains what that pipeline actually is, in plain language, and for anyone who wants to pull the same data themselves, includes working code and links to the real tools involved.

What Is ERA5?

ERA5 is the fifth-generation atmospheric reanalysis produced by the European Centre for Medium-Range Weather Forecasts (ECMWF). "Reanalysis" means it isn't raw observation data — it's what you get when you combine millions of real observations (satellites, weather stations, ships, balloons) with a physics-based numerical weather model, run backward through history, to produce a single, consistent, gap-free climate record. ERA5 covers 1940 to near-present, at roughly 31km horizontal resolution globally.

ERA5-Land, which this site uses wherever available, is a refined version focused specifically on land-surface variables — temperature, precipitation, soil moisture — at a much finer ~9km resolution, produced by rerunning ECMWF's land-surface model at higher resolution using ERA5's atmospheric fields as input.

Who Produces and Funds It?

ERA5 is produced by ECMWF and distributed through the Copernicus Climate Change Service (C3S), the European Union's Earth observation program. It's publicly funded, scientifically peer-reviewed, and used as a foundational dataset across climate science, agriculture, energy, insurance, and — as this site demonstrates — independent climate journalism.

The Data Pipeline Behind This Site

1
ECMWF produces ERA5/ERA5-Land — the raw reanalysis, distributed via the Copernicus Climate Data Store (CDS).
2
Open-Meteo ingests this data and provides it through a free, simplified Historical Weather API — no account or API key required for the volumes used on this site, which is why it's the practical entry point we use rather than querying the CDS directly.
3
Python queries that API for each city's coordinates, pulling daily temperature and precipitation values across the full 1995/96–2025 study window.
4
Aggregation & trend analysis — daily values are grouped into years and seasons (following standard South Asian meteorological conventions), then a linear regression trend line is fitted to show the 30-year direction.
5
Publication — the resulting charts and figures become the reports across this site, each with its own methodology note.

How to Access This Data Yourself

ERA5 is genuinely free and open. If you want to pull it yourself, here's what's actually involved:

Option 1: Open-Meteo (what this site uses)

The simplest route — no account needed for historical queries. Here's a minimal working example in Python, close to what powers this site's own dashboard:

import requests
import pandas as pd

def fetch_historical_weather(lat, lon, start_year, end_year):
    url = "https://archive-api.open-meteo.com/v1/archive"
    params = {
        "latitude": lat,
        "longitude": lon,
        "start_date": f"{start_year}-01-01",
        "end_date": f"{end_year}-12-31",
        "daily": ["temperature_2m_mean", "precipitation_sum"],
        "timezone": "auto"
    }
    response = requests.get(url, params=params)
    data = response.json()["daily"]
    df = pd.DataFrame(data)
    df["time"] = pd.to_datetime(df["time"])
    df["year"] = df["time"].dt.year
    return df

# Example: Karachi, Pakistan
df = fetch_historical_weather(24.8607, 67.0011, 1996, 2025)
print(df.head())

Option 2: Copernicus Climate Data Store (direct source)

For full control over variables, resolution, and format, ECMWF's own Climate Data Store is the authoritative source — free with registration, accessed via their cdsapi Python package.

GitHub Resources for ERA5

ECMWF doesn't host the dataset itself on GitHub, but several genuinely useful GitHub-hosted tools exist for working with it:

  • AWS Open Data Registry — ERA5: cloud-hosted ERA5 data with example notebooks for direct access without downloading full files.
  • github.com/topics/era5: a broad index of open-source projects, scripts, and research code built on ERA5, spanning meteorology, machine learning, and climate hazard research.
  • ECMWF's own tooling: packages like cfgrib (for reading ERA5's native GRIB format in Python) and ecmwf-opendata are maintained by ECMWF for programmatic access.
Why this site doesn't query the CDS directly: the Copernicus Climate Data Store is the authoritative source, but its API requires registration, has request queuing for large downloads, and returns data in formats (GRIB/NetCDF) that need additional processing before they're chart-ready. Open-Meteo handles that conversion and serves the same underlying ERA5/ERA5-Land data through a simple REST API — the right tradeoff for a site publishing accessible climate journalism rather than raw scientific datasets.

Limitations Worth Knowing

  • Resolution limits in complex terrain. ERA5-Land's ~9km grid cells can't fully resolve valley-specific microclimates — a caveat we flag explicitly in our Rasuwagadhi report, where narrow Himalayan gorge terrain sits well below that grid scale.
  • Reanalysis vs. direct observation. ERA5 is a model-assisted product, not a raw station record — it can differ from a specific weather station's own historical log, particularly in data-sparse regions or before the satellite era.
  • Urban effects are only partially captured. Local urban heat island effects, as discussed in our Islamabad winter warming piece, aren't fully separable from broader regional signals at this resolution.

Frequently Asked Questions

What is ERA5?

ERA5 is the fifth-generation atmospheric reanalysis produced by the European Centre for Medium-Range Weather Forecasts (ECMWF), combining satellite and ground-station observations with a numerical weather model to produce a consistent, gap-free historical climate record from 1940 to near-present, at roughly 31km resolution globally (ERA5-Land refines this to about 9km over land).

Is there an ECMWF GitHub for accessing ERA5 data?

ECMWF doesn't host ERA5 data directly on GitHub, but several GitHub-hosted tools and repositories provide access or wrappers around it — including ECMWF's own cfgrib and ecmwf-opendata Python packages, the AWS Open Data Registry's ERA5 listing, and community tools like KrigR (R) for downloading and downscaling ERA5/ERA5-Land data. This site itself uses the Open-Meteo Historical Weather API, a free wrapper around ERA5/ERA5-Land that avoids needing direct Copernicus Climate Data Store API credentials.

Is ERA5 data free to access?

Yes. ERA5 is freely available through the Copernicus Climate Data Store (CDS) with a free account, and also through simplified third-party APIs like Open-Meteo, which this site uses, requiring no API key or account for historical weather queries.

How accurate is ERA5 reanalysis data compared to ground weather stations?

ERA5 is generally very accurate for large-scale, flat terrain, but its accuracy decreases in areas of complex topography — mountain valleys, coastlines, and cities with strong local microclimate effects — because its grid resolution (roughly 9–31km) can't fully resolve features smaller than that. This site flags this limitation explicitly for locations like Rasuwagadhi, in complex Himalayan terrain.

What is the difference between ERA5 and ERA5-Land?

ERA5-Land is a higher-resolution (~9km vs ~31km) version of ERA5 focused specifically on land surface variables like temperature and precipitation, produced by running ECMWF's land-surface model at finer resolution using ERA5's atmospheric data as input. This site uses ERA5-Land where available for improved local accuracy.
